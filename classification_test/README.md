# Classification test

Utilities and scripts used for **classification** experiments and checks (separate from `mosaic_test/` and `legacy/`).

## Contents

| Subfolder | Description |
|-----------|-------------|
| [`test_tile_selection/`](test_tile_selection/) | Google Earth Engine script to pick representative MGRS test tiles over Chile (see that folder’s `README.md`). |

## Layout

This is **two nested directories** in the repository (not a single folder name):

```text
classification_test/           ← folder at repo root
└── test_tile_selection/       ← folder inside classification_test
    ├── README.md
    └── test_tile_selection.js
```

On GitHub, open **`classification_test`**, then open **`test_tile_selection`** inside it.
